# Database Performance Research (Yandex Practicum, 2023)

[English](README.md) | [Русский](README.ru.md)

A public copy of a team learning project completed during the Yandex Practicum course. It studies database performance and user-data queries with ClickHouse, MongoDB and Vertica.

My contribution was testing Vertica.

## Research materials

| Database | Setup and research guide | Scripts and recorded results |
| --- | --- | --- |
| ClickHouse | [ClickHouse study](clickhouse/readme.md) | [Scripts](clickhouse/) and [results](clickhouse/results/) |
| MongoDB, first setup | [MongoDB study](mongodb/mongo1/readme.md) | [Configuration and scripts](mongodb/mongo1/) |
| MongoDB, second setup | [MongoDB study](mongodb/mongo2/readme.md) | [Configuration and scripts](mongodb/mongo2/) |
| Vertica | [Vertica study](vertica/readme.md) | [Test scenarios](vertica/run_tests/) and [results](vertica/results/use_case.md) |

The database directories contain Python test scripts, dependency lists and Docker configuration. The linked guides describe data insertion, reads and user scenarios. Use each database's guide for its setup and commands.
