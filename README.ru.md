# Исследование производительности БД (Яндекс Практикум, 2023)

[English](README.md) | [Русский](README.ru.md)

Публичная копия командного учебного проекта в рамках обучения в Яндекс Практикуме. Исследует производительность баз данных и запросы к пользовательским данным в ClickHouse, MongoDB и Vertica.

Мой вклад — тестирование Vertica.

В каталогах баз данных находятся тестовые скрипты Python, списки зависимостей и настройки Docker. По ссылкам описаны добавление данных, чтение и пользовательские сценарии. Настройка и команды для каждой базы приведены в ее инструкции.
